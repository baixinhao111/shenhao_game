# 03. UI 交互规范与视觉设计方案（Mobile-First H5 / PWA）

> **设计核心理念**：玩家是在**手机浏览器**里点链接游玩，因此 UI 本身就是最好的沉浸感来源。我们不追求笨重过时的传统页游贴图按钮，而是打造一种 **「顶级私行黑卡 App × 科幻神豪系统 HUD × 仿真手机微信社交」** 的极致现代质感。

---

## 一、视觉风格与设计系统（Design Tokens）

### 1. 整体美学方向：**黑金奢华 + 霓虹微光系统（Obsidian Gold & Cyber HUD）**
- **主背景色**：深曜石黑 `#0A0B0F` / 卡片微透磨砂 `#141720`（`backdrop-filter: blur(12px)`，细金边 `rgba(212, 175, 55, 0.22)`）
- **核心财富高亮色**：流光尊金 `#E6C165` → `#F9DF8B`（用于现金、暴击返现、身价数字、VIP/阶层徽章）
- **系统科技高亮色**：天枢霓虹青 `#38BDF8` / `#22D3EE`（用于系统蓝屏弹窗、洞察眼扫描、任务提示、AI 思考状态）
- **暴击 / 警示 / 红点色**：炽热绯红 `#F43F5E`（用于 10x/100x 暴击炸屏、好感爱心、微信未读红点、反派挑衅标记）
- **文字层级**：主白 `#F8FAFC`、次灰 `#94A3B8`、弱化 `#64748B`；**所有数字一律使用 `tabular-nums` 等宽数字字体**，保证金额快速滚动跳动时绝不左右抖动！

### 2. 屏幕适配规范
- **手机端（主力场景）**：原生 100% 适配 9:16 至 9:20 全面屏（兼容 iOS Safe Area 底部小黑条），全屏无横向滚动，90% 高频操作单手拇指可达。
- **电脑端（开发与桌面访问）**：居中渲染一个精致的 `max-width: 430px` 手机视口容器，外部配深色渐变氛围背景，确保电脑上测试和游玩同样完美。
- **PWA 支持**：配置 `manifest.json` + App 图标，朋友在 Safari/Chrome 点“添加到主屏幕”后自动隐藏浏览器地址栏，体验等同原生 App。

## 二、爽感微交互与视听反馈规范（Juice 引擎）

哪怕没有 3D 引擎，做到以下 5 个交互细节，爽感也能直接拉满：

1. **数字滚动引擎**：现金/身价增加绝不生硬跳变，统一采用 0.6s 缓动滚轮增长 + 上浮 `+¥10,000,000` 金色飘字。
2. **暴击返现全屏演出**：触发 5x 以上暴击时，屏幕边缘泛起金色扫光、轻微震屏（Android 同步调用 `navigator.vibrate([40, 30, 80])`）、中央弹出【天枢暴击 · ×10 返现到账】炫光横幅 + 粒子金币飞向顶部现金栏。
3. **高仿手机顶部推送通知（Toast）**：
   - 离线收菜或返现到账时，顶部滑出高仿“招商/私人银行短信到账通知”；
   - 红颜主动发消息或朋友圈有新点赞时，顶部滑出高仿“微信新消息横幅”，点击直接跳转聊天！
4. **打脸弹幕层（Barrage Overlay）**：主线名场面与直播间 PK 时，半透明弹幕从右向左密集飞过（先是反派/路人嘲讽，你拍出筹码后一秒全屏变金色吹捧弹幕）。
5. **纯前端合成音效（Web Audio API）**：零额外大音频加载，用代码精准合成清脆的“叮！”系统激活音、金币哗啦到账音、微信提示音、打字气泡音、切石开玉爆裂音（顶部设置一键静音开关）。

## 四、逐页详细交互与布局设计

### 1. 【剧情】页：追剧式主线 + 支线入口
- **大厅视图**：
  - 顶部大片感**当前章节横幅卡片**（背景图 + 卷章标题 + 进度条 + 醒目的金色【继续推进】按钮）；
  - 下方横向切换：`主线连载` / `红颜个人线` / `已解锁回忆录`。
- **沉浸剧场视图（全屏隐藏底部 Tab）**：
  - 上半屏：高清都市背景图 + 半身立绘（支持表情切换、淡入震动） + 顶部半透明弹幕层；
  - 居中悬浮层：**【天枢系统蓝屏弹窗】**（触发任务、洞察扫描、三选一卡牌、身价检定进度条）；
  - 下半屏：磨砂黑金对话框（说话人名牌 + 打字机字幕 + 右上角 `自动/倍速/历史记录` 按钮）。

### 2. 【资产】页：产业帝国 + 藏品陈列馆
- 顶部大字展示：**总估值 & 每小时总现金流（+¥125万/小时）**，右侧醒目金色按钮**【一键收菜】**（带离线倒计时环）。
- 两个子 Tab：
  - **旗下产业**：卡片列表，每张卡片展示产业图标、等级、产出效率、**已委派红颜头像（点开可换人）**、一键升级按钮（支持 ×1 / ×10 升级）。
  - **名下资产图鉴**：按 `豪车 / 豪宅 / 游艇飞机 / 稀世藏品` 分类的暗金玻璃陈列卡片，带**套装收集进度条**与【购买 / 设为座驾展示】按钮。

### 3. 【红颜】页：后宫档案 + 高仿微信 AI 私聊 + 朋友圈
- **红颜列表视图**：精美立绘卡片流，展示每位红颜的当前关系阶位、好感进度条、商业加成标签、**未读消息小红点**；顶部带入口切换**【朋友圈】**。
- **红颜详情 & 互动操作区**：
  - 顶部大立绘展示（支持点击立绘触发随机微表情/台词）；
  - 四个核心动作键：`💬 微信私聊（AI）`、`🎁 赠送礼物（触发返现）`、`🌹 邀请约会`、`📖 个人剧情`。
- **AI 微信私聊视图（核心亮点）**：
  - 高度还原微信深色模式质感：顶部显示名字 + 关系徽章 + 动态状态（如“正在输入中…”）；
  - 聊天气泡上方可展开**“系统洞察微提示”**（显示她此刻的隐藏心情/内心 OS 潜台词，瞬间拉满神豪爽文感！）；
  - 底部输入框支持自由打字 + 快捷话题芯片（怕玩家不知道聊什么时提供 3 个顺手话题） + 快捷【发红包/送礼】按钮，送完立刻在聊天流里弹出“已收款”卡片并触发 AI 实时惊喜回复！
- **朋友圈视图**：展示主角的装逼动态与红颜/反派的实时点赞评论，玩家可对动态点赞或选回复。

### 4. 【海城】页（默认首页）：两级城市大地图 + 多房产拜访 + 区域小玩法
- **一级视图（海城全景电子沙盘）**：
  - 暗夜黑金风格都市全景地图，支持丝滑拖动与顶部区划标签快切（`全城` / `老街` / `大学城` / `外滩` / `CBD` / `不夜城` / `半山海岸` / `国际航线`）；
  - 地图地标上动态浮动 **主线感叹号**、**红颜当前位置头像气泡**、**已购豪宅/冠名写字楼金色标志**、**码头限时活动游轮横幅**；
  - 右侧悬浮极简快捷条：`🚗 当前座驾切换`、`📋 今日快捷导览（防跑图繁琐）`、`🏆 小圈子财富榜`。
- **二级视图（区域内街景大厅）**：
  - 顶部区域氛围横幅（展示当前区域名、时段天气、当前驾驶座驾与【返回大地图】按钮）；
  - **在场 NPC 栏**：横向展示此刻在该区域的红颜头像，点击直接开启约会或带场景上下文的 AI 对话；
  - **核心玩法 & 轻互动卡片组**：直观卡片入口（如老街的 `🪨 古玩赌石街`、`🍜 深夜大排档`、`👣 街头闲逛奇遇`；CBD 的 `📈 模拟股市`、`💼 总裁决策台`、`✨ 大楼灯光秀`；不夜城的 `🎤 直播间 PK`、`🌟 星探签约` 等）；
  - **本区房产入口**：展示该片区可购置或已拥有的房产卡片，点击已购房产直接**进入私宅室内视图**（可切换为主居所、查看/邀请入住红颜触发居家互动、逛地下车库与藏宝室、升级精装）。

### 5. 【系统】页：天枢外挂本体
- 顶部充满未来感的**【天枢核心等级环】** + 当前最高暴击倍率展示 + **保底暴击充能进度条**；
- 子 Tab：`每日/周常任务`、`系统词条技能树`（3 列直观加点树）、`系统商城`、`个人背包`。

### 6. 管理员 GM 轻量后台（`/admin` 独立路由，仅密码可见）
- 专为小圈子“服主”打造：
  - 查看朋友们的游玩进度与 AI Token 每日消耗统计；
  - 一键给指定玩家或全服发送**【系统福利邮件】**（如补偿现金/精力/限定道具）；
  - 开关限时活动、调整活动时间、热重载服务器上的新剧本/新红颜 JSON 配置。
