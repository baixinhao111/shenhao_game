## 一、核心世界观：现实都市之下的「北斗七枢」

### 1. 世界基调：「海城夜金」新现实主义神豪
- **表世界**：当代国际都会**海城**——城南青石旧街与地下玉市、海城大学银杏大道、外滩老洋房与江景名利场、陆家湾摩天玻璃幕墙、星耀不夜城霓虹、云顶半山深水海岸与公务机航站。社会规则高度写实：职场甩锅、阶层壁垒、实业现金流、股权质押、媒体舆情、豪门联姻，**绝无无脑降智配角，也绝无凭空撒币的廉价感**。
- **暗世界（全书核心母题）**：十年前（2016 年「海城黑天鹅金融风暴」），七位东亚实业与金融巨擘秘密共建了一套跨市场主权风控与实业清算网络——**「北斗七枢（The Seven Pivots）」**，用于抵御国际离岸资本对本土核心产业与金融命脉的恶意做空与收割。
  - 七枢分工：**天枢（总账与清算授信）**、天璇（风控与离岸对冲）、天玑（政商与法规通道）、天权（实业与土地供应链）、玉衡（传媒与舆情定价）、开阳（情报与密码加密）、摇光（世家信用互保）。
  - 陆沉的父亲**陆渊**是「天枢」首席架构师与总账受托人。
  - **2016 风暴之夜**：七枢内部出现「零号叛徒（天璇席位）」，联手外部离岸空头反手猎杀陆氏实业、瓜分海城底盘。陆渊在失踪前夕强行启动**「零号静默协议（Protocol Zero）」**——冻结核心清算池十年，将总账主权拆分为**「血脉终端」**与散落各地的**「七枚星轨凭证」**，只待十年静默期满，在唯一继承人陆沉经历底层淬炼、心性定型后的深秋雨夜自动解封。

### 2. 「天枢系统」的写实化设定（与游戏机制 100% 自洽）
- **消费暴击返现（2–10×）**：陆渊设下的**「实业杠杆试炼」**。继承人不可白领空钱挥霍，唯有将资金投入实体产业、核心物业、资产标的或高价值人脉建设，天枢离岸清算池才会按撬动系数自动释放对应倍率的冻结本金；未触发时自动积攒清算权重（返现蓄能），满 100% 必出高倍返现。
- **全维洞察（读心 / 赌石透视 / 谈判底价 / 股市实时内参与异动预警 / 21 点透视暗牌）**：直连全球股权穿透图谱与暗盘资金流，并融合微表情、声纹波动与全谱光学扫描模块。
- **天枢积分与进修**：反映宿主「节点主权信任度」，用于解锁更高阶算法模块（返现率/倍率、复利管理、并购压价、气度魅力）与关键危机推演。
- **序章未觉醒期铁律**：`ep_001` 23:55 静默协议解封前，陆沉是彻头彻尾的普通社畜——无天枢弹窗、无右上角终端按钮、无心声读心。

## 五、写作与验收铁律
1. 每幕 **55–70 节点**（2500–3500 字精炼剧本），包含 **2 个有完整分支演绎（6–8 节点）的选择点**、**3–5 句高信息量 `innerThought`**、精准镜头动效（`shake`/`flash`/`impact`/`heartbeat`）与高钩子 `cliffhanger`。
2. **仅使用仓库实际存在的背景图与立绘路径**，无立绘配角不伪造路径；每处选择必保留至少一个 `cost: { cash: 0 }` 免费选项以防卡死。
3. 改完主线必更新 `content/maps/haicheng.json`（`requireEpisode`）、`content/heroines/heroines.json`（`unlockHint` & `systemPrompt`）、`server/src/empire.ts`（剧情股节点），并跑通 `balance_progress.mjs --suggest`、`check_content.mjs` 与 `api_minigames.test.mjs`。
